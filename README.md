## Featured projects

### [Modulation Classifier](https://github.com/temmatan/modulation-classifier)

A Python neural-network project that classifies BPSK, QPSK, and 16QAM signals across multiple signal-to-noise ratios, with PCA and confusion-matrix visualizations.

### [Snake in Assembly](https://github.com/temmatan/snake_in_assembly)

A terminal Snake game written in pure x86-64 NASM assembly for Linux, including direct keyboard input, terminal rendering, movement, growth, and collision handling.

### [Network Debug Toolkit](https://github.com/temmatan/network_debug_toolkit)

A lightweight Bash toolkit for common Linux network diagnostics, including connectivity checks, DNS lookup, traceroute, port scanning, and interface inspection.

### [Engineering Portfolio](https://github.com/temmatan/portfolio)

A personal engineering portfolio and blog built with Next.js, Tailwind CSS, and Framer Motion to present projects, technical writing, and experience.
